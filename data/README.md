# Data identifiers

All inputs are public. Place files under `data/raw/` with the names below.

| File / folder | Source | Identifier |
|---|---|---|
| `K562_gwps_normalized_bulk_01.h5ad` | Replogle et al. 2022, Cell 185:2559 | figshare+ release accompanying the paper (DOI 10.25452/figshare.plus.20029387) |
| `K562_essential_normalized_bulk_01.h5ad` | Replogle et al. 2022 | same release |
| `encode/K562/chip/*.bed.gz`, `encode/K562/atac/*.bed.gz`, HepG2 equivalents | ENCODE | accession per file in `data/raw/encode_manifest.tsv` (conservative IDR thresholded peaks; ATAC ENCFF333TAT for K562) |
| `jaspar2024_vert_nr.txt` | JASPAR 2024 CORE vertebrates, non-redundant (MEME/JASPAR format) | jaspar.elixir.no |
| `probound/MotifCentral.v1.0.0.json` | MotifCentral v1.0.0 (ProBound models) | motifcentral.org |
| `upstream1000.fa.gz`, `refGene.txt.gz` | UCSC hg38 | hgdownload.soe.ucsc.edu/goldenPath/hg38 |
| `norman/norman2019.h5ad` | Norman et al. 2019, Science 365:786 | GEO GSE133344 (processed h5ad) |
| `scperturb/WesselsSatija2023.h5ad`, `scperturb/ShifrutMarson2018.h5ad` | scPerturb (Peidli et al. 2024) | scPerturb Zenodo release |

Derived caches (`data/processed/`) are regenerated by the commands in `run_all.sh`.
