# Final tests F1–F6 (numeric results)

Scripts: `experiments/final_replogle.py` (F1, F2), `experiments/final_synthetic.py` (F3, F4, F5), `experiments/final_context.py` (F6). JSON in `results/final/`. Manuscript: `paper/main.pdf` (tables in `paper/tables/` generated by `scripts/make_tables.py`).

| Test | Key metric | Value | Meaning |
|---|---|---|---|
| F1 domino share (Replogle, 507 reproducible KDs) | corr of cascade prediction with independent screen (K=5–50) vs random-mediator null | −0.008 to −0.013 vs −0.004 to +0.003; share mean 0.003 | Linear one-step cascades explain ~0 of the specific signal |
| F2 benchmark (1,396 held-out KDs) | mean profile corr: same-screen raw / other-screen raw / other-screen specific | 0.340 / 0.247 / −0.003 | Specific target removes "mean wins" artefact |
| F2 | best predictor (kNN-50) on specific target | 0.065 (ceiling ≈ 0.22) | Specific part is barely predictable; factorised ≠ better |
| F3 memory (clean, fluctuating regulators) | AUROC hidden-regulator detection vs control | 0.84 ± 0.17 vs 0.51 ± 0.11 | Works in principle |
| F3 | AUROC at measurement noise 0.25 / 0.5 × sd; sampling ≥ 0.5 | 0.71 / 0.49; ≤ 0.46 | Fails under realistic noise / sparse sampling |
| F3 | timescale recovery; latent rank | Spearman 0.22 (p=0.36); rank ≈ 14–22 for 0–4 hidden | Both failed |
| F4 three-gene | spurious coef = c·b·λ (theory vs sim) | 0.50/0.50 obs; 0.10/0.10 B perturbed | Formula verified; Lasso still selects |
| F4 80-gene | indirect FP rate: src perturbed vs not (mediator unperturbed); hidden mediator | 5.9% vs 5.1%; 15–17% | Attraction small; hidden mediators dominate |
| F4 | identifiability flag precision flagged vs unflagged | 0.27 vs 0.44 | Modestly informative |
| F5 prior forms (AUPRC×) | none / soft site / hard identity / identity+site / hard binding | 15.5 / 18.6 / 22.2 / 23.2 / 7.3 | Mask who regulates; don't mask by binding |
| F5 depth | held-out KD corr D=1 vs deeper (stabilised plateau) | 0.50 vs 0.44 | No gain from deep propagation; needs stability |
| F6 Wessels | sign flips context vs null; fold gain change | 1.09% vs 0.07%; 1.20 vs 1.12 | Gain-not-wiring replicates |
| F6 Shifrut | strong shared targets in split-half null | 6–12 total | Underpowered, inconclusive |

Limitations: simulator-based F3–F5 (identity mask exact; hidden-fluctuation regime chosen to allow detection; shallow held-out cascades); F1 linear and limited to knocked-down mediators; selection (item 6) not tested on real data.
